# T-006: Entwicklung und Debugging im Docker-Container

## Ziel

API und Frontend laufen während der Entwicklung im Container `app`, damit auf dem Host außer Docker und einem Editor nichts installiert sein muss und überall dieselbe Node-Version gilt. Der Produktionsbetrieb mit `docker compose up --build -d` bleibt unverändert.

## Akzeptanzkriterien

- [ ] Ein Befehl startet `db` und `app` im Entwicklungsmodus mit dem Quellcode aus dem Repo
- [ ] Änderungen an API-Code starten die API im Container neu, Änderungen am Frontend erreichen den Browser per HMR, auch auf einem Windows-Host
- [ ] Ein Debugger aus VS Code hält an einem Breakpoint im TypeScript-Code der API im Container
- [ ] Der Debug-Port ist nur auf `127.0.0.1` des Hosts erreichbar
- [ ] `pnpm check` läuft im Container grün
- [ ] Das Produktions-Image und `docker compose up --build -d` verhalten sich wie zuvor

## Definition of Done

- `make check` grün
- Akzeptanzkriterien vom `reviewer` bestätigt
- `PROGRESS.md` und `status` aktualisiert (`/handoff`)
