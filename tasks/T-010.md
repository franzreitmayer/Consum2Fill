# T-010: Stammdaten mit Lagerorten

## Ziel

Es gibt das neue Hauptmenü „Stammdaten“, auf das die Rollen ADMIN und MANAGER zugreifen. Dort pflegen sie die Inhalte der Entität Lagerort. Der Bereich „Administration“ mit der Benutzerverwaltung bleibt auf ADMIN beschränkt.

## Akzeptanzkriterien

- [ ] Es gibt das Hauptmenü „Stammdaten“. ADMIN und MANAGER sehen es und können darauf zugreifen, USER nicht.
- [ ] „Lagerorte“ liegt unter „Stammdaten“, nicht unter „Administration“.
- [ ] „Administration“ mit der Benutzerverwaltung bleibt nur für ADMIN sichtbar und zugänglich.
- [ ] Die Liste zeigt alle Lagerorte mit Nummer und Name.
- [ ] Lagerorte können erstellt, geändert und gelöscht werden. Das Löschen muss vorher bestätigt werden.
- [ ] Das Löschen ist nur möglich, wenn kein Verbrauch und keine Bestellung auf den Lagerort verweist. Andernfalls wird eine entsprechende Fehlermeldung ausgegeben.
- [ ] Ein doppelter Name wird abgelehnt und die Meldung im Formular angezeigt.
- [ ] Lade- und Fehlerzustände sind sichtbar, der Bereich funktioniert ab 360 px Breite und per Touch.

## Hinweise

- Die API erlaubt das Schreiben von Lagerorten bereits ADMIN und MANAGER (ADR 0005), die Benutzerverwaltung unter `/api/admin` nur ADMIN. Eine Änderung an API oder Vertrag ist deshalb nicht nötig.
- Verbrauch und Bestellung haben noch keine Oberfläche. Bezüge auf einen Lagerort lassen sich deshalb vorerst nur über die API entfernen, verwendete Lagerorte bleiben in der Oberfläche unlöschbar.
